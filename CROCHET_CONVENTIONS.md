# Common Crochet Pattern Conventions and Abbreviations

This document is a practical reference for reading or parsing common crochet
patterns. Unless a section says otherwise, stitch names use **US terminology**.

> [!IMPORTANT]
> A pattern's own abbreviation list or symbol key always takes precedence.
> Crochet notation is widely shared, but it is not perfectly universal.

## The `sc` and `X` distinction

These can describe the same stitch, but they belong to different notation
systems:

| Meaning | US written pattern | UK written pattern | International/Japanese chart | Chinese XVA shorthand |
|---|---|---|---|---|
| Single crochet | `sc` | `dc` | `×` or `+` | `X` or `x` |

- `sc` is an English-language abbreviation for **single crochet** in US terms.
- `×` or `+` is a **graphical stitch symbol**, not specifically a Japanese or
  Chinese abbreviation. It is especially common in Japanese stitch diagrams.
- `X` in a Chinese amigurumi pattern is usually a text-friendly form of the
  single-crochet chart symbol.
- The UK name for the same physical stitch is **double crochet** (`dc`).

| `lp`, `lps` | loop, loops | |

### Basic stitches and actions (US terms)

| Abbreviation | Meaning |
|---|---|
| `MR` | magic ring |
| `MC` | magic circle **or** main color; determine from context |
| `ch` | chain |
| `sl st` | slip stitch |
| `sc` | single crochet |
| `hdc` | half double crochet |
| `dc` | double crochet |
| `tr` | treble crochet |
| `dtr` | double treble crochet |
| `yo` | yarn over |
| `yoh` | yarn over hook |
| `inc` | increase |
| `dec` | decrease |
| `tog` | together; used to form decreases or clusters |

`MR` is less ambiguous than `MC`, because `MC` also commonly means **main
color**.

### Counts, increases, and decreases

| Notation | Meaning | Input stitches | Output stitches |
|---|---|---:|---:|
| `2 sc in next st` | single-crochet increase | 1 | 2 |
| `sc inc`, `sc-inc`, `inc` | usually 2 single crochets in one stitch | 1 | 2 |
| `sc2tog` | single crochet 2 together | 2 | 1 |
| `sc3tog` | single crochet 3 together | 3 | 1 |
| `dc2tog` | double crochet 2 together | 2 | 1 |
| `inv dec` | invisible single-crochet decrease | 2 | 1 |
| `3 sc in next st` | three-stitch single-crochet increase | 1 | 3 |

An increase adds one stitch only when it produces two stitches from one. A
three-stitch increase produces a net gain of two. Likewise, a `2tog` decrease
has a net change of -1, while a `3tog` decrease has a net change of -2.

### Placement and orientation

| Abbreviation | Meaning |
|---|---|
| `FLO`, `FL` | front loop only / front loop |
| `BLO`, `BL` | back loop only / back loop |
| `tbl` | through back loop |
| `tfl` | through front loop |
| `FP` | front post |
| `BP` | back post |
| `FPdc` | front-post double crochet |
| `BPdc` | back-post double crochet |
| `FLsc` / `BLO sc` | single crochet in the specified loop |

Loop stitches and post stitches are different: `BLO` is worked through part of
the stitch's top loops, while `BP` is worked around the stitch's vertical post.

## US and UK terminology

US and UK stitch names are offset for most tall stitches. Identify the system
before interpreting `dc`, `tr`, or similar abbreviations.

| Physical stitch | US term | UK term |
|---|---|---|
| Slip stitch | slip stitch (`sl st`) | slip stitch (`ss`) |
| No yarn-over before insertion | single crochet (`sc`) | double crochet (`dc`) |
| One yarn-over; pull through all three loops | half double crochet (`hdc`) | half treble (`htr`) |
| One yarn-over; pull through two loops twice | double crochet (`dc`) | treble (`tr`) |
| Two yarn-overs | treble crochet (`tr`) | double treble (`dtr`) |
| Three yarn-overs | double treble crochet (`dtr`) | triple treble (`trtr`) |

Other vocabulary differences include US `gauge` versus UK `tension`, and US
`skip` versus UK `miss`.

## Chart-symbol conventions

Charts describe stitches graphically. Symbols often resemble the structure of
the finished stitch. Font and publisher differences make a pattern's legend
authoritative.

| Common symbol or shape | Usual US meaning |
|---|---|
| Oval or open circle | chain (`ch`) |
| Solid dot | slip stitch (`sl st`) |
| `×` or `+` | single crochet (`sc`) |
| T-shaped post, no slash | half double crochet (`hdc`) |
| T-shaped post, one slash | double crochet (`dc`) |
| T-shaped post, two slashes | treble crochet (`tr`) |
| T-shaped post, three slashes | double treble crochet (`dtr`) |
| Two stitch symbols spreading from one base | increase |
| Two stitch symbols sharing one top | decrease / `2tog` |

For tall-stitch symbols, each additional slash normally represents another
yarn-over before insertion.

## Chinese XVA shorthand

Compact Chinese-language amigurumi patterns often use Latin letters derived
from stitch-chart shapes. This is a popular shorthand rather than one globally
enforced standard.

| Token | Usual meaning in US terms | Input | Output |
|---|---|---:|---:|
| `X` / `x` | single crochet (`sc`) | 1 | 1 |
| `V` / `v` | single-crochet increase: 2 `sc` in one stitch | 1 | 2 |
| `A` / `a` | single-crochet decrease: `sc2tog` | 2 | 1 |
| `W` / `w` | 3 `sc` in one stitch | 1 | 3 |
| `M` / `m` | 3 single crochets together (`sc3tog`) | 3 | 1 |
| `T` / `t` | half double crochet (`hdc`) | 1 | 1 |
| `F` / `f` | double crochet (`dc`) | 1 | 1 |

Modifiers are often combined with the base stitch. For example, `FV` commonly
means a double-crochet increase and `FA` a double-crochet decrease. Always check
the supplied key because less common tokens vary among designers.

Common Chinese stitch names are:

| Chinese | Pinyin | US term |
|---|---|---|
| 锁针 | suǒ zhēn | chain |
| 引拔针 | yǐn bá zhēn | slip stitch |
| 短针 | duǎn zhēn | single crochet |
| 中长针 | zhōng cháng zhēn | half double crochet |
| 长针 | cháng zhēn | double crochet |
| 长长针 | cháng cháng zhēn | treble crochet |

## Japanese chart terminology

Japanese patterns are commonly presented as stitch diagrams rather than as XVA
text. The `×` symbol normally means `細編み`, the stitch called single crochet
in US terms.

| Japanese | Romanization | US term | Common chart shape |
|---|---|---|---|
| くさり編み / 鎖編み | kusari-ami | chain | oval |
| 引き抜き編み | hikinuki-ami | slip stitch | solid dot |
| 細編み | koma-ami | single crochet | `×` or `+` |
| 中長編み | chūnaga-ami | half double crochet | T-shaped post |
| 長編み | naga-ami | double crochet | T-shaped post with one slash |
| 長々編み | naganaga-ami | treble crochet | T-shaped post with two slashes |

Japanese charts often show increases by drawing multiple symbols from one base
and decreases by joining multiple symbols at the top. Round or row numbers and
arrows indicate order and working direction.

## Repeats, grouping, and stitch totals

| Form | Typical interpretation |
|---|---|
| `* sc, inc; rep from * around` | Repeat `sc, inc` to the round's end |
| `[sc, inc] x 6` | Repeat the bracketed sequence six times |
| `(sc, inc) 6 times` | Repeat the parenthesized sequence six times |
| `6(sc, inc)` | Often the same repeat in compact/XVA notation |
| `(12)` or `[12]` at line end | Expected stitch count after the row or round |
| `in same st` | Work the grouped stitches into one input stitch |
| `each` | Apply the instruction to every specified stitch |

Brackets and parentheses can mean either **repeat this group** or **work this
group into the same stitch**. Read the surrounding words and the pattern's own
conventions.

### Equivalent amigurumi examples

| Result | US written notation | Chinese XVA-style notation |
|---|---|---|
| Six stitches in a magic ring | `Rnd 1: 6 sc in MR (6)` | `R1: 6X (6)` |
| Increase in every stitch | `Rnd 2: inc around (12)` | `R2: 6V (12)` |
| Alternate one stitch and one increase | `Rnd 3: (sc, inc) x 6 (18)` | `R3: 6(X, V) (18)` |
| Alternate two stitches and one increase | `Rnd 4: (2 sc, inc) x 6 (24)` | `R4: 6(2X, V) (24)` |
| Alternate two stitches and one decrease | `Rnd 5: (2 sc, dec) x 6 (18)` | `R5: 6(2X, A) (18)` |

## Terms that require a pattern-specific definition

The following names describe families of stitches, but their exact construction
can differ among designers:

- `bob` or bobble
- `CL` or cluster
- `puff`
- `pc`, `pop`, or popcorn
- `shell`
- `V-st` or V-stitch
- `picot`
- `spike st`
- `crossed dc`

Do not infer their loop count, number of component stitches, or stitch-count
effect without the pattern's special-stitch instructions.

## Parsing and normalization recommendations

For software, retain both the source token and a normalized operation. Useful
canonical operations include:

```text
CHAIN
SLIP_STITCH
SINGLE_CROCHET
HALF_DOUBLE_CROCHET
DOUBLE_CROCHET
TREBLE_CROCHET
INCREASE(base_stitch, output_count)
DECREASE(base_stitch, input_count)
REPEAT(sequence, count)
WORK_IN_LOOP(front | back | both)
WORK_AROUND_POST(front | back)
```

Recommended parsing rules:

1. Detect the terminology system (`US`, `UK`, chart, or XVA) before mapping
   tokens.
2. Treat the pattern's local legend as the highest-priority dictionary.
3. Preserve case when reading the source, but compare common XVA tokens
   case-insensitively unless the legend distinguishes them.
4. Store both input-stitch consumption and output-stitch production.
5. Validate each stated end-of-row count, but allow for turning chains and slip
   stitches that the designer explicitly excludes from the count.
6. Record whether rounds are joined or continuous; this changes topology even
   when the stitch sequence is identical.
7. Do not assume a turning chain counts as a stitch. Patterns differ and should
   state this explicitly.
