# English idioms

| English | CrochetPARADE |
| --- | --- |
| "Ch 16" (foundation) | `16ch`, with `turn` when the next row works back along it |
| "sc in 2nd ch from hook" | `sk,sc` |
| "dc in 4th ch from hook" | `3sk,dc` |
| "magic ring", "MR", "adjustable ring" | `ring.R` on its own line; the next round works `@R` |
| "6 sc in ring" | `6sc@R` |
| "ch 4, join with sl st to form a ring" | `4ch.R,ss@[%,0]` |
| "inc", "2 sc in next st" | `sc2inc` |
| "3 dc in next st" | `dc3inc` |
| "dec", "sc2tog", "invdec" | `sc2tog` (an invisible decrease is noted as an assumption) |
| "dc2tog" | `dc2tog` |
| "sc in each st around/across" | `Nsc`, with N from the previous row's count |
| "(sc, inc) 6 times", "*sc, inc; rep from * around" | `6*[sc,sc2inc]` |
| "sl st to first sc to join" | `ss@[%,0]`, or `ss@[%,1]` after a leading `ch` |
| "join with sl st to top of beg ch-3" | `ss@[%,2]` |
| "ch 1, turn" at the end of a row | `turn` ends this line; `ch` starts the next |
| "beginning in the first st", "starting with the first stitch" | The usual order after a turn (`Nsc`, `Ndc`): it names where the row starts, not a change of direction; never `@[-1,0]` for it |
| "ch 3 (counts as dc)" at the start of a row | `3ch,sk,…` |
| "dc in top of turning ch" | `dc@[-1,2]` when the previous line began with `3ch` |
| "skip next 2 sts" | `2sk` |
| "in the same st" | `@[@]`: `dc,dc@[@]`, `sc,2ch,sc@[@]` |
| "ch 3, skip 2 sts, sc in next st" (space used later) | `3ch.A[0],2sk,sc` |
| "3 dc in next ch-3 sp" | `3dc@A[0]` (the label given when the space was made) |
| "BLO", "in back loop only" / "FLO" | `scbl`, `dcbl` / `scfl`, `dcfl` |
| "FPdc", "dc around front post" / "BPdc" | `fpdc` / `bpdc` |
| "sl st", "slip stitch" | `ss` |
| "change to B", "with B" | `COLOR:` line with B's colour name |
| "Rnds 4–7: sc around" | 4 lines |
| "fasten off", "weave in ends", "stuff" | empty translation |
